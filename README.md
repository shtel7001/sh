# KOSPI 500 뉴스 급등 레이더 V2

기존 사이트를 건드리지 않고 별도 브랜치/배포로 재구축한 개인용 레이더입니다.

## 핵심 구조
- KOSPI 시가총액 상위 500종목을 50종목 × 10단계로 수집
- 네이버 금융 종목목록 + Yahoo Finance 실제 일봉 교차 사용
- 최근 N거래일의 설정 가능한 급등 기준 탐지
- 급등일 전 N일의 네이버 뉴스 선행 여부 검증
- 다음 거래일 후보는 가격·거래량·최근 뉴스 기반 **관찰점수**로 정렬
- 단계별 자동 재시도 + 실패 구간만 재분석
- 수집 실패값은 임의값으로 대체하지 않음
- `.xlsx` 엑셀 저장

## 인증 환경변수
- `RADAR_PASSWORD`: 최초 개인 인증 비밀번호
- `SESSION_SECRET`: 24자 이상 서명용 문자열

한 번 로그인하면 서명된 HttpOnly 세션 쿠키를 사용합니다.

## 선택 환경변수
- `NAVER_CLIENT_ID`
- `NAVER_CLIENT_SECRET`

네이버 검색 API가 없거나 실패하면 네이버 금융 종목뉴스 페이지 수집으로 폴백합니다.
