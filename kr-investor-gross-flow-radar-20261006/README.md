# KR 투자자 총매수·총매도 레이더

개별 종목·날짜별로 외국인, 기관합계, 개인의 **매수수량 / 매도수량 / 순매수 / 총회전량 / 상계율 / 평균매수가 / 평균매도가**를 확인하는 Vercel 웹앱입니다.

## 데이터
- KRX Data Marketplace
- 투자자별 거래실적(개별종목): `MDCSTAT02302`
- 개별종목 시세: `MDCSTAT01701`
- 종목 검색: `finder_stkisu`

KRX 로그인 정책으로 인증이 필요한 경우 Vercel 환경변수에 `KRX_ID`, `KRX_PW`를 설정하면 서버 함수가 로그인 세션을 사용합니다. 자격증명은 GitHub 소스에 저장하지 않습니다.

## 핵심 계산
- 총회전량 = 매수수량 + 매도수량
- 양방향 매칭가능량 = min(매수수량, 매도수량)
- 양방향참여율 = 총회전량 / (시장거래량 × 2) × 100
- 상계율 = (1 - |순매수| / 총회전량) × 100
- 평균매수가 = 매수대금 / 매수수량
- 평균매도가 = 매도대금 / 매도수량

상계율이 높다는 것은 해당 투자자군 안에서 매수와 매도가 동시에 컸다는 뜻이지, 동일 계좌의 당일 왕복매매를 직접 증명하는 지표는 아닙니다.
